上一篇写的是我给 Herdr 补了个右键菜单，就为了复制文件路径。

那篇发出去之后，Along 又长了不少。今天接着写这两处改动。一处让终端能浮出布局，一处把 agent 收进项目里。

# 终端被钉在布局里

Herdr 把终端、文件面板和 agent 放在一个窗口里。窗格一多，我常想把一个终端单独拎出来，比如让它跑个长任务，自己接着在别处干活，不用一直惦记着它。可它挪不动，想临时看别的只能切来切去。

于是给面板头部加了个 **Float** 按钮。点一下，这个窗格的终端会被停下（park）。它还在跑，只是从布局里挪出去，装进一个能随手拖动的浮动窗口。想放哪放哪。

![Float 按钮：点一下把终端浮出去](https://img.51ai.vip/20261117150642675.png)

# 悬浮容易，放回去难

我第一个念头是看浮动窗口被拖到了哪，再判断该放回哪个窗格旁边。这条路走不通，Herdr 的 mod API 拿不到被拖窗口的屏幕矩形，也拿不到各个窗格的矩形，我根本不知道你把窗口拖到了哪。靠猜送回去，十次有九次是错的。

后来换了个笨办法。**不猜位置，直接让你点**。先点一下目标窗格，再用方向键选放回哪一侧。

在浮动窗口上点一下主布局里想靠近的那个窗格，把它记成目标。浮动条上有 **← → ↑ ↓** 四个方向按钮，按一下，终端就插到目标的左 / 右 / 上 / 下。

![浮动窗口与四个方向按钮](https://img.51ai.vip/20261117150650411.png)

还有个坑。Herdr 的命令不是调用完立刻生效的，`run` 返回之后还得等一会儿。我最早的版本命令一发完就去读状态、去分屏，读到的是旧的，于是不管按哪个方向，终端一律往右插。后来每一步都等命令真正落地再往下走，才正常。

现在浮出去的窗口会记住位置，关掉重开还在。点「↙ send back」能把终端送回它原来的 space 和 tab，连位置一起还原。

![点 send back，终端回到原来的位置](https://img.51ai.vip/20261117150718673.gif)

# 侧边栏合成一个列表

第二个别扭的地方在侧边栏。以前 space（项目）是一个列表，agent 是另一个列表。我同时开着好几个项目、每个项目下又挂着好几个 agent 的时候，想知道这个 agent 到底属于哪个项目，得在两个列表之间来回对名字。对完过一会儿又忘了，还得再对一遍。

看着累。

改法很直接，每个 space 下面直接跟着它自己的 agent。

每个 agent 行上带着几样东西。

- **程序图标**，点一下折叠它下面的子 agent
- **名字**
- **机器名**，远程的才显示
- **状态标记**，转圈是在干活，红色 `!` 是卡住等你处理，做完了是实心点，闲着是空心圈

扫一眼就知道哪个项目在忙、哪个 agent 卡着、哪个已经收工。

![合并且带状态标记的侧边栏](https://img.51ai.vip/20261117150722946.png)

层级顺着项目往下走。主 checkout 的 agent 缩进一档，worktree 再深一档，子 agent 更深一层。一个 worktree 跟在它主项目的 agent 后面，带着自己那层 agent。归属看缩进就清楚，不用另外去对名字。

排序上，置顶的排最前，剩下的按要紧程度来。卡住的、完成的、干活的、闲着的，同级里最近有动静的靠前。不属于任何列出来的项目的 agent，比如跑在别的机器上的那些，统一归到末尾的 **Elsewhere**。

折叠起来的时候侧边栏只显示项目，清爽。原来那个独立的 Agents 区域连同排序菜单从布局里撤了，代码还留在仓库里，哪天想用再挂回来。

# 装来试试

跟上篇一样，把这句话丢给你的 agent。

```
Read ~/.config/herdr-app/AGENTS.md, then add this layout:
https://github.com/chenweil/herdr-along/tree/main/along
```

仓库里两个包，按需要选。

| 包              | 类型     | 说明                                                                                |
| -------------- | ------ | --------------------------------------------------------------------------------- |
| `along`        | Layout | 完整窗口。Float 浮动窗格、合并后的 agent 列表都在这个包里。装完在设置 `Look` → `LAYOUT` 里选 **along** |
| `along-panels` | Mod    | 只有面板，不动你现有的窗口布局。Files 默认停右侧，Changes 自己摆                                  |

只要面板的话，把地址换成 `.../tree/main/along-panels`，提示词里的 `layout` 换成 `mod`。

两个新功能都在 `along` 这个完整布局包里，`along-panels` 只有 Files / Changes / Machines 那几样，不含浮动窗格和合并列表。想用上它们，装 `along` 就行。

Mod 是受信任的代码，不在沙箱里跑。这些包会调 `sh` / `powershell` 列目录、调 `git` 取仓库状态、用 `hc` 管机器、用 `readTextFile` 读预览。包本身不联网，但 Changes 面板的 **Commit** 是真的会提交（`git add -A` + `git commit`）。

介意的话，只留 Files 面板的复制功能，把 `along-changes` 从安装目录里删掉就行。

这两个包的面板是 Herdr 自带面板的改造版，不跟着上游自动更新。Herdr 升级后，得重新同步再改一遍。这点我写在 RECIPE 里了。
